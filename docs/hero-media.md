# Фоновое видео TEIKO

Проверено и подготовлено 15 сентября 2026 года для первого экрана витрины TEIKO.

## Сцена и источник

Реальная съёмка профессиональной мойки: оператор наносит пену на автомобиль
в тёмном боксе. Мягкий холодный свет, водяная взвесь и движения распылителя
поддерживают тему автохимии. Визуальная палитра самого сайта задаётся поверх
видео средствами CSS.

- Автор: Tima Miroshnichenko.

Видео подготовлено установленным FFmpeg: уменьшено до Full HD, перекодировано
через `libx264 -preset slow -crf 25`, звук исключён, добавлен `+faststart` для
быстрого начала воспроизведения. Последние 0,6 с плавно переходят в первые
0,6 с исходной сцены; начало результата сдвинуто на 0,6 с, что сохраняет
непрерывность движения при повторе. Постер извлечён из готового видео.

Бинарные файлы хранятся вне Git в `public/assets/cinematic/`. Для нового
окружения их нужно передать через хранилище артефактов либо восстановить из
источника. Исходный 4K-файл после обработки удалён.

## Восстановление

Скачать исходный MP4 по ссылке выше во временный файл и выполнить:

```powershell
New-Item -ItemType Directory -Path public/assets/cinematic -Force | Out-Null
ffmpeg -i source.mp4 -filter_complex '[0:v]scale=1920:1080,split=2[main][head];[main]trim=start=0.6,setpts=PTS-STARTPTS[body];[head]trim=end=0.6,setpts=PTS-STARTPTS[opening];[body][opening]xfade=transition=fade:duration=0.6:offset=13.4,format=yuv420p[out]' -map '[out]' -c:v libx264 -preset slow -crf 25 -an -movflags +faststart -t 14 public/assets/cinematic/teiko-detailing.mp4
ffmpeg -i public/assets/cinematic/teiko-detailing.mp4 -frames:v 1 -q:v 3 public/assets/cinematic/teiko-detailing-poster.jpg
```

Версия FFmpeg может влиять на побайтовые контрольные суммы при повторном
кодировании. Проверять также разрешение, длительность, отсутствие звука и
корректность декодирования.
