# Редизайн TEIKO по визуальному референсу Hipershield

Дата исследования: 15 сентября 2026.

## Цель и результат

Перенести композицию и характер движения [Hipershield](https://hipershield.ru/)
на существующую витрину TEIKO: фирменный зелёный, автомобильное видео,
сохранённые каталог, административный контент и внешняя покупка.

## Проверенные особенности референса

Исследованы первый экран и последовательность секций в браузере, а также
публичные [стили](https://hipershield.ru/wp-content/themes/ndg-quantum/css/main.css)
и [скрипт анимаций](https://hipershield.ru/wp-content/themes/ndg-quantum/js/common.js).

| Референс | Реализация TEIKO |
| --- | --- |
| Большое затемнённое видео, абсолютная шапка | Съёмка нанесения пены, логотип TEIKO и три якоря |
| Montserrat, белый/чёрный, красный акцент | Montserrat, белый/тёмно-зелёный, `#48b45a` |
| Короткая цветная черта рядом с H2 | Зелёные линии и номера разделов |
| Прелоадер: 1 с, уход вверх за 0,5 с | CSS-заставка, не блокирующая ввод и не зависящая от JS |
| Лента партнёрских логотипов | Лента представленных брендов и направлений, без выдуманных партнёров |
| Появления снизу и справа | Однократный IntersectionObserver reveal, без библиотек |
| Две колонки товарных карточек | Действующий каталог с поиском и фильтрами, две колонки |
| Кнопка карточки приезжает снизу за 0,3 с | Проявляющийся зелёный CTA, постоянно доступный на малом экране |
| Фотосетка: крупный кадр и четыре меньших | Пять изображений категорий, открывающих фильтр каталога |
| Чёрная секция контактов и дилеры | Тёмная инструкция покупки и ссылка на магазин TEIKO |

Композиция адаптирована под автохимию. Чужие тексты, логотипы, видео, дилеры,
формы заявок и исходный код не перенесены. У референса не обнаружены GSAP,
WebGL, закрепление секций или сложный скролл-параллакс; они не заявляются
частью переноса.

## Сохранённые функции

- `/api/storefront` и резервный `/storefront.json`;
- админские изображения, тексты, порядок и ссылки промослайдов;
- категории, поиск, цена, описание, характеристики и marketplace-ссылки;
- существующая закрытая админка и страница `/teiko/`;
- пользовательские тексты настроек; точные устаревшие seed-тексты заменены
  новой подачей только при отображении, без изменения базы.

Новая публичная страница использует `storefront.css` и `storefront.js`.
Старые `styles.css`, `app.js` и API визуальных пресетов сохранены, но пресеты
предыдущего оформления на новую страницу не применяются.

## Видео и доступность

[Медиа-манифест](hero-media.md) содержит источник, лицензию и восстановление
локальных файлов. MP4 и постер исключены из Git; при публикации их нужно
включить в артефакт сайта. Это подготовленная съёмка со стока, не AI-видео.

У видео и промослайдов есть кнопки паузы. Скрытая вкладка прекращает
воспроизведение. При reduced motion анимации и автоматическое видео выключены,
при экономии трафика видео не скачивается автоматически. Каталог и текст
остаются читаемыми, если декоративные эффекты не поддерживаются.

## Проверка

Синтаксис JavaScript, структура HTML, локальные ссылки на ресурсы, кодировка,
экранирование контента, безопасные URL и соответствие DOM-контракта проверяются
отдельно от запуска. Стандартная серверная проверка проекта — `npm run check`.
Для запуска по GI требуется доступный config-service либо явное отключение
его интеграции в проекте. Публикация на внешний хостинг — отдельная операция.
