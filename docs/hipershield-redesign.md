# Редизайн TEIKO по визуальному референсу Hipershield

Дата исследования: 15 сентября 2026.

## Цель и результат

Перенести композицию и характер движения [Hipershield](https://hipershield.ru/)
на существующую витрину TEIKO: фирменный зелёный, автомобильное видео,
сохранённые каталог, административный контент и внешняя покупка.

## Проверенные особенности референса

Исследованы первый экран и последовательность секций в браузере, а также
публичные [стили](https://hipershield.ru/wp-content/themes/ndg-quantum/css/main.css)
и [скрипт анимаций](https://hipershield.ru/wp-content/themes/ndg-quantum/js/common.js).

| Референс | Реализация TEIKO |
| --- | --- |
| Большое затемнённое видео, абсолютная шапка | Съёмка нанесения пены, логотип TEIKO и три якоря |
| Montserrat, белый/чёрный, красный акцент | Montserrat, белый/тёмно-зелёный, `#48b45a` |
| Короткая цветная черта рядом с H2 | Зелёные линии и номера разделов |
| Прелоадер: 1 с, уход вверх за 0,5 с | Заставка TEIKO держится около 3 с, уходит вверх за 0,7 с; шапка и текст появляются после неё, без JS контент сразу виден |
| Лента партнёрских логотипов | Представленные бренды в равных ячейках: одинаковый шаг за 0,5 с, остановка 1,5 с, бесшовное повторение |
| Появления снизу и справа | Однократный IntersectionObserver reveal, без библиотек |
| Две независимые колонки товарных карточек | Каталог с поиском и фильтрами; раскрытие сдвигает следующий товар только в своей колонке |
| Кнопка карточки приезжает снизу за 0,3 с | Нижний отступ увеличивается на 60 px, CTA выходит снизу по центру: bottom −100 → 10 px; на сенсорном устройстве кнопка постоянно видна |
| Фотосетка: крупный кадр и четыре меньших | Пять изображений категорий, открывающих фильтр каталога |
| Чёрная секция контактов и дилеры | Тёмная инструкция покупки и ссылка на магазин TEIKO |

Композиция адаптирована под автохимию. Чужие тексты, логотипы, видео, дилеры,
формы заявок и исходный код не перенесены. У референса не обнаружены GSAP,
WebGL, закрепление секций или сложный скролл-параллакс; они не заявляются
частью переноса.

## Сохранённые функции

- `/api/storefront` и резервный `/storefront.json`;
- админские изображения, тексты, порядок и ссылки промослайдов;
- категории, поиск, цена, описание, характеристики и marketplace-ссылки;
- существующая закрытая админка и страница `/teiko/`;
- пользовательские тексты настроек; точные устаревшие seed-тексты заменены
  новой подачей только при отображении, без изменения базы.

Новая публичная страница использует `storefront.css`, `storefront.js` и модуль
`storefront-effects.js` (пошаговая лента и независимые колонки).
Старые `styles.css`, `app.js` и API визуальных пресетов сохранены, но пресеты
предыдущего оформления на новую страницу не применяются.

## Видео и доступность

[Медиа-манифест](hero-media.md) содержит источник, лицензию и восстановление
локальных файлов. MP4 и постер исключены из Git; при публикации их нужно
включить в артефакт сайта. Это подготовленная съёмка со стока, не AI-видео.

У видео, ленты брендов и промослайдов есть кнопки паузы. Скрытая вкладка
прекращает воспроизведение. Анимации включены при каждом открытии страницы;
кнопка явно показывает это состояние. Отключение действует только до обновления
страницы и останавливает автоматическое видео и переходы. Прежнее сохранённое
значение `teiko.motion` больше не читается. Ссылки на секции прокручивают
страницу плавно при включённом движении.
При экономии трафика видео не скачивается автоматически. Каталог и текст
остаются читаемыми, если декоративные эффекты не поддерживаются.
Товарные изображения получают новую версию URL после публикации; при сбое
загрузки карточка пробует файл ещё раз и показывает оформленную заглушку,
если повторная попытка не удалась.

## Уточнение по записи пользователя

Разобрана запись `MultiSnap-20260915-194952.mp4` (43,83 с). Кадры анализа
находятся в локальной игнорируемой папке `data/motion-review/`.

- 0–6 с: движение первого экрана создаётся фоновым видео.
- 8–14 с: логотипы двигаются шагами с остановками.
- 20–24 с: раскрывается нижняя часть карточки, затем сдвигается следующий
  товар той же колонки. Размер фотографии сохраняется.
- При обратном скролле секции остаются раскрытыми. Отдельный параллакс
  и привязка видеокадров к прокрутке записью не подтверждаются.

В проверяемом браузере `prefers-reduced-motion: reduce` был включён: прежняя
версия полностью отключала динамику, а входы hero в обычном режиме завершались
ещё под заставкой. Исправлены оба механизма. Появления секций идут однократно
за 1 с; невидимый элемент смещён на 100 px вниз, блок care-copy — вправо.
Включение движения заново подготавливает только секции ниже экрана.

## Проверка

Синтаксис JavaScript, структура HTML, локальные ссылки на ресурсы, кодировка,
экранирование контента, безопасные URL и соответствие DOM-контракта проверяются
отдельно от запуска. Стандартная серверная проверка проекта — `npm run check`.
Для запуска по GI требуется доступный config-service либо явное отключение
его интеграции в проекте. Публикация на внешний хостинг — отдельная операция.

Предыдущая версия проверялась в живом браузере при ширине 1257 и 390 px: явное включение при
системном reduce, воспроизведение видео,
мобильное меню, диалог товара, поиск с пустым результатом и возврат каталога.
При раскрытии первой карточки её высота выросла с 541 до 601 px, позиция
следующей в левой колонке — с 573 до 633 px; правая осталась на 599 px.
На 390 px абсолютные позиции снимаются, горизонтального переполнения нет.

Повторная сверка с записью показала и исправила два отличия: CTA теперь
выезжает строго по центру, а ячейки ленты стали одинаковой ширины. В
браузере шаги составляют 258,25 px на ширине 1257 px и 174 px на ширине
390 px; все четыре перехода каждой группы одинаковы. После раскрытия
карточки CTA и карточка имеют один центр (318,5 px), высота остаётся
601 px, следующая левая карточка — на 633 px, правая — на 599 px.
Медиасцена TEIKO выбрана в рамках темы автоухода: это нанесение пены,
тогда как референс показывает работу с защитной плёнкой.

Последние изменения проверены синтаксически и через статическую сборку:
12 товаров, 7 промослайдов, все локальные изображения на месте. На публичном
`teiko.unity-constructor.site` опубликованные HTML, CSS, JS и JSON совпадают
с локальными файлами по SHA-256; все 21 изображение и медиафайл отвечают
HTTP 200 с ожидаемым размером. Публикация использует `npm run build:static`
и выбранный проектом шлюз, не прямую загрузку из репозитория.
